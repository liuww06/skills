# invest 插件分析规范

本文件是 `invest` 插件所有技能共享的报告规范。各技能输出报告时必须遵守。

## 报告通用规范

1. **标题**：包含标的 / 主题名称，并注明「截至最新可得数据」。禁止写死具体日期、点位、价格 —— 数据随时间失效，报告必须保持模板通用性。
2. **结构**：按各技能 SKILL.md 中定义的输出模板逐节输出，不遗漏章节。
3. **引用格式**：`来源：东方财富（URL 或页面名，YYYY-MM-DD）`。页面无日期标注时写「日期未标注」。
4. **不确定性分级**：结论与关键判断使用三级表述：
   - **确认**：≥2 个独立来源交叉验证一致
   - **大概率**：单一可靠来源，或有佐证但未完全交叉验证
   - **存疑**：来源单一且可靠性一般，或来源间存在分歧
5. **数据矛盾处理**：并列列出不同来源的数字并说明分歧来源，不擅自取舍。

## 合规红线

1. 不承诺收益，不使用「保证盈利」「必涨」「稳赚」等表述。
2. 买卖相关结论仅以「框架性参考」表述，明确最终决策由投资者自行作出。
3. 不针对个股给出确定性目标价；估值区间须注明方法与假设。
4. 涉及未公开信息猜测时明确标注「推测」并说明依据。

## 统一免责声明（所有技能报告结尾逐字使用）

> 免责声明：本报告由 AI 基于公开网络信息生成，仅供参考，不构成任何投资建议（非投资建议）。数据可能滞后或有误，请以官方披露为准。投资有风险，入市需谨慎。

## 时效与检索纪律

1. 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取最新数据，数据源清单见 `data-sources.md`。
2. 关键数字须 ≥2 个独立来源交叉验证，无法核实标注「未核实」。
3. 用户未提供标的 / 主题时：输出使用说明与分析框架并询问，**不发起联网检索**。
4. 报告中区分「事实」（有来源）与「分析」（模型推断），推断处使用「判断 / 推测」字样。
