# invest 插件共享数据源清单

本文件是 `invest` 插件所有技能的共享数据源索引。各技能在做真实联网检索前应先读本文件，选择合适的来源与检索式。

使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取数据；不依赖任何本地脚本或付费数据接口。

## 来源优先级规则

1. **法定披露源**（公司公告、官方统计）最优先，数字以法定披露为准。
2. **主流财经媒体 / 官方机构网站** 次之（东方财富、财新、央行、美联储等）。
3. **自媒体 / 论坛**（雪球讨论、公众号转载等）仅作线索，不作为关键数字的引用来源。

关键数字（涨跌幅、财务数据、政策条目、宏观数值）须有 **≥2 个独立来源交叉验证**；无法核实的一律标注「未核实」。所有引用必须标注数据日期。

## 检索式模板

- 公司财报：`<公司名或代码> 年报 业绩` / `site:cninfo.com.cn <公司名> 公告`
- 业绩预告：`<公司名> 业绩预告 <年度或季度>`
- 北向资金：`北向资金 净买入 最新`
- 板块资金：`<板块名> 资金流向 主力净流入`
- 宏观数据：`<指标名，如 CPI / PMI / 社融> 最新 同比` / `site:stats.gov.cn <指标>`
- 利率政策：`LPR 报价 最新` / `site:pbc.gov.cn 货币政策`
- 美联储：`FOMC statement 最新` / `美联储 议息会议 决议`
- 美债与美元：`site:fred.stlouisfed.org 10-year treasury` / `美元指数 最新`
- 关税与管制：`USTR 301 关税 中国` / `BIS entity list 新增` / `<公司名> 实体清单`
- 行业景气：`<行业名> 景气度 / 产能 / 库存 / 开工率 最新`
- 技术面行情页：`<代码> 东方财富 行情` / `<公司名> 同花顺 K线`

## 取数规则

1. 每个关键数字标注 `来源（站点，YYYY-MM-DD）`；页面无日期时标注「日期未标注，未核实」。
2. 行情类数据波动快，报告统一表述为「截至最新可得数据」，不写死具体日期与点位。
3. 检索结果互相矛盾时并列列出并说明分歧，不擅自取舍。
4. 付费墙或无法访问的来源，换用同优先级替代来源，不猜测数据。
