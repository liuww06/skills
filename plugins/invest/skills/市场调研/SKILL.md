## 适用场景

- 用户询问大盘走势、市场情绪、涨跌结构、热点板块、资金面（北向资金 / 两融 / 主力资金）等 A 股整体市场问题时触发本技能。
- 中文提问示例：「今天大盘怎么样」「帮我复盘本周的市场情绪和热点板块」。
- 英文提问示例："give me an overview of the A-share market" / "how is the market sentiment and northbound flow today"。
- 边界：个股基本面与财报分析走公司研究类技能；宏观政策与海外市场解读走宏观类技能；本技能聚焦 A 股整体与板块结构。

## 输入确认

本技能参数可选，未指定时默认按「最近一个交易日的大盘复盘」处理。

- 若用户既未提供关注点（如今日行情、本周复盘、情绪、资金面、某热点板块），也未表达任何相关意图（例如只是问「这个技能是什么、怎么用」）：输出使用说明与分析框架概览并询问想看哪方面，此情形下【不发起联网检索】。
- 用户一旦给出主题（某板块、某类资金、情绪面），或明确要求分析（哪怕只是泛泛的『最近怎么样』），即视为输入已确认，直接按本文件框架检索执行，不再反复追问。
- 用户指定了范围（当日 / 本周 / 某时间段，或只看某几个维度）时，按指定范围裁剪输出模板章节（这是 analysis-conventions.md「不遗漏章节」规则在用户明确限定范围时的唯一例外）；未提及的维度在报告中省略并注明「按用户要求未覆盖」；引用标注、置信度分级与结尾免责声明不可裁剪。

## 数据检索

1. 检索前先读 `../../references/data-sources.md`（从本技能文件出发的相对路径），按其中的来源优先级规则与取数规则执行。
2. 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取最新数据，不依赖本地脚本或付费数据接口。
3. 本技能核心来源（内联速查，完整清单以 data-sources.md 为准）：
   - 东方财富（eastmoney.com / data.eastmoney.com）：指数行情、成交额、板块资金流向、北向资金、两融余额、龙虎榜。
   - 同花顺（10jqka.com.cn）：行情、板块涨跌、资金流向、技术指标页面，与东方财富互为交叉验证源。
   - 财联社（cls.cn）：盘面快讯、盘中异动、题材电报，用于热点驱动逻辑与消息面线索。
   - 雪球（xueqiu.com）：仅作热点线索与讨论方向参考，不作为关键数字的引用来源。
4. 可直接执行的检索式示例（风格参照 data-sources.md 的检索式模板，按需替换 <占位符>）：
   - `上证指数 深证成指 创业板指 成交额 最新`
   - `北向资金 净买入 最新` / `<板块名> 资金流向 主力净流入`
   - `财联社 盘面快讯 涨停 复盘` / `A股 涨停家数 炸板率 <日期或时段>`
5. 检索结果互相矛盾时并列列出并说明分歧；遇付费墙或无法访问的来源，换用同优先级替代来源，不猜测数据。

## 分析框架

按以下五个维度组织分析：先取数、再判断，事实与分析分开陈述，推断处使用「判断 / 推测」字样。

### ① 指数与量能

- 分析什么：上证指数、深证成指、创业板指、科创50 的当日与阶段涨跌、相对强弱；两市及分市场成交额及其环比变化；量能处于放大、萎缩还是持平阶段。
- 怎么判断：对比四大指数涨跌幅识别风格分化（权重与成长的跷跷板）；用量价配合评估健康度（放量上涨优于缩量上涨，放量下跌最弱）；成交额的连续变化方向比单日数字更能说明资金参与度。
- 警惕什么：不要用单一指数代表全貌（常见上证持平而个股普跌的分化结构）；不要只看涨跌幅不看量能；不要把缩量反弹直接推断为趋势反转。

### ② 情绪温度计

- 分析什么：上涨 / 下跌家数、涨停 / 跌停家数、炸板率、最高连板高度、昨日涨停股今日表现（赚钱效应）。
- 怎么判断：涨跌家数比用于区分普涨普跌与结构性分化行情；炸板率升高叠加连板高度下降，通常指示情绪退潮；指数红而赚钱效应差时，警惕权重护盘、题材失血。
- 警惕什么：涨停家数多不等于可参与性强（可能集中在一字板）；情绪指标日内波动大，取数须标注时点与来源；不同口径的涨停统计（是否含 ST、是否含北交所）差异大，引用时须注明口径。

### ③ 资金面

- 分析什么：北向资金净流入 / 净流出（当日与近阶段累计）、两融余额及变化方向、主力资金净流入 / 净流出居前的板块。
- 怎么判断：北向与两融的趋势方向比单日净额更重要；主力净流入板块应与领涨板块互相印证，判断资金共识程度；资金集中于少数板块还是分散轮动，决定行情性质（主线市 / 轮动市）。
- 警惕什么：北向资金披露口径如有调整（停更、降频），须注明数据可得性，不臆测缺口；单日净流入噪音很大，避免过度解读；「主力资金」各家口径不同，引用时注明来源与口径。

### ④ 热点主线

- 分析什么：领涨板块及其驱动逻辑（政策、事件、业绩、海外映射）、主线的持续性判断、板块轮动节奏。
- 怎么判断：驱动逻辑是否有后续催化（政策落地节奏、事件日历）决定持续性上限；量能配合且龙头梯队完整（龙头 + 跟风 + 补涨）的主线更持久；热点单日切换、缺乏接力通常指示存量博弈。
- 警惕什么：不要把纯消息脉冲当成新主线；对已连续领涨、情绪过热的板块须提示拥挤度与回撤风险；不得仅凭雪球等社区讨论热度下结论。

### ⑤ 后市观察点

- 分析什么：重要事件日历（政策会议、宏观数据发布、海外央行议息等）、关键指数技术位、潜在变盘信号。
- 怎么判断：输出观察清单而非方向预测；技术位（整数关口、前高前低）的突破或站稳须配合量能确认才有意义；变盘信号关注量能突变、情绪极值与事件催化的共振。
- 警惕什么：严禁给出确定性方向判断或具体点位预测（合规红线）；技术位一律用 <占位符> 表述，不写死点位；观察点控制在 <数量> 条左右，避免重点模糊。

## 引用与时效

- 每个关键数字（涨跌幅、成交额、家数、资金净额等）标注来源与数据日期，格式：`来源：东方财富（URL 或页面名，YYYY-MM-DD）`；页面无日期标注时写「日期未标注，未核实」。
- 关键数字须有 ≥2 个独立来源交叉验证（东方财富 × 同花顺为常用组合），无法核实的一律标注「未核实」。
- 行情数据波动快，全文统一用「截至最新可得数据」表述，不写死具体日期、点位与价格。
- 结论与关键判断按三级置信度标注：**确认**（≥2 个独立来源交叉验证一致）、**大概率**（单一可靠来源，或有佐证但未完全交叉验证）、**存疑**（来源单一且可靠性一般，或来源间存在分歧）。
