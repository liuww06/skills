## 适用场景

用户要求对某家上市公司做基本面 / 全景研究，或追问某公司「基本面怎么样」「值不值得长期关注」时触发本技能。典型提问：
- 中文：「帮我全面研究一下 <公司名> 的基本面」「<公司名> 的护城河、财务质量和估值帮我分析一下」
- 英文："Give me a fundamental analysis of <company name>"、"What is <company name>'s moat and is it fairly valued?"
- 触发后输出一份覆盖业务、护城河、治理、财务、估值、风险的公司全景研究报告，不构成投资建议。

## 输入确认

本技能必须先有明确标的（公司名称或股票代码）才能执行，缺标的时不做任何联网检索。

若用户未提供任何标的：
1. 【不发起联网检索】。
2. 输出本技能的使用说明与分析框架概览：说明可分析七大维度——公司概况、业务拆解、护城河、管理层与治理、财务质量、估值、风险与催化剂。
3. 列出各维度能回答的典型问题（如「收入靠什么业务赚的钱」「管理层有没有乱花钱」「现在估值贵不贵」），并询问用户要分析哪家公司。

用户提供标的后，先确认标的唯一性：公司名与集团 / 上市主体 / 同名公司存在歧义时向用户澄清，再进入数据检索。

## 分析框架

### ① 公司概况
- 分析什么：主营业务与产品、上市板块（沪深主板 / 创业板 / 科创板 / 北交所或境外）、股权结构与实际控制人、市值量级。
- 怎么判断：以最新年报「公司简介」「控股股东及实际控制人情况」为基准，实控人链条追至自然人或国资主体为止。
- 警惕什么：实控人不清晰、多层嵌套股权架构、板块定位与业务实质不符的，相关判断标注「存疑」。

### ② 业务拆解
- 分析什么：收入按产品 / 地区 / 商业模式拆分（年报「主营构成」），识别增长引擎业务与拖累业务。
- 怎么判断：对每项业务做量价拆解（销量、单价、产能利用率、渗透率），判断成长驱动是否可持续；前五大客户与供应商集中度单独列示。
- 警惕什么：业务描述宏大但收入构成模糊；单一客户或供应商占比畸高；盲目多元化分散资源。

### ③ 护城河
- 分析什么：品牌、成本优势、网络效应、转换成本、技术壁垒（专利 / 工艺 / 牌照）逐项评估，各给「强 / 中 / 弱」结论与依据。
- 怎么判断：结合波特五力简化版（供应商议价力、客户议价力、新进入者威胁、替代品、行业内竞争）；用相对同行的持续毛利率差异、提价能力、客户留存作证据。
- 警惕什么：把周期性景气或政策补贴误认成护城河；壁垒依赖单一牌照或核心专利到期。

### ④ 管理层与治理
- 分析什么：核心管理层背景与任职年限、创始人及管理层持股、股权质押比例、历史减持记录、股权激励覆盖面与考核目标。
- 怎么判断：质押、减持、激励数据以法定披露与交易所数据页交叉核对；资本配置历史（分红、回购、并购）逐项列示并评价。
- 警惕什么：高比例质押、频繁大额减持、激励考核目标过松、审计非标意见、频繁更换会计师事务所。

### ⑤ 财务质量
- 分析什么：杜邦分解（ROE = 净利率 × 总资产周转率 × 权益乘数），判断盈利模式是高利润率、高周转还是高杠杆驱动。
- 怎么判断：拉长多期观察毛利率与净利率趋势并与同行对比；经营现金流 / 净利润比长期偏低则利润含金量存疑；应收账款与存货增速对照收入增速；商誉占净资产比例及减值历史；有息负债结构与短债覆盖。
- 警惕什么：大存大贷并存、收入增长但经营现金流持续为负、商誉与应收异动、利润依赖非经常性损益。

### ⑥ 估值
- 分析什么：PE / PB / PEG / 股息率及各自历史分位（注明静态 / 滚动 / 预期口径），以及当前市值对应的业务构成。
- 怎么判断：编制可比公司估值表（业务与规模相近的 <可比公司> 若干家）；DCF 只给思路——增长、折现率、永续增长的假设区间与敏感性，不给确定性目标价。
- 警惕什么：单看 PE 下结论；周期股误用低 PE 判断便宜；估值区间不注明方法与假设。

### ⑦ 风险与催化剂
- 分析什么：主要风险（政策与监管、竞争格局恶化、成本波动、技术替代、解禁减持、商誉减值、债务到期）与潜在催化剂（新产能投放、新品类放量、政策扶持、行业出清、回购增持）。
- 怎么判断：风险与催化剂成对呈现，各附观察信号与可跟踪指标；对尚未落地事项标注「推测」并说明依据。
- 警惕什么：只列利好不列风险；把规划中的产能或产品当成既成事实计入结论。

## 引用与时效

1. 每个关键数字标注来源与日期，格式统一为 `来源：东方财富（URL 或页面名，YYYY-MM-DD）`；页面无日期时标注「日期未标注，未核实」。
2. 关键数字（财务数据、质押与减持、估值指标等）须 ≥2 个独立来源交叉验证；无法核实的标注「未核实」；检索结果矛盾时并列列出并说明分歧，不擅自取舍。
3. 报告统一用「截至最新可得数据」表述，不写死具体日期、价格与点位。
4. 结论与关键判断按三级置信度标注：**确认**（≥2 个独立来源交叉验证一致）、**大概率**（单一可靠来源，或有佐证但未完全交叉验证）、**存疑**（来源单一且可靠性一般，或来源间存在分歧）。
5. 区分「事实」（有来源）与「分析」（模型推断），推断处使用「判断 / 推测」字样。
