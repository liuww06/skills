## 适用场景

- 用户想从技术面角度看某只个股（趋势、均线、指标、量价、支撑阻力、形态）时触发本技能。
- 中文提问示例：「贵州茅台技术面怎么样」「帮我看看 <标的> 的 K 线结构和支撑位」。
- 英文提问示例："technical analysis of <ticker>" / "check the moving averages and MACD for <stock>"。
- 边界：公司基本面、财务与估值走公司研究类技能；财报解读走财报类技能；本技能只做技术面与量价分析，并在结论中提示与基本面交叉验证。

## 分析框架

按以下七个维度组织分析。全篇必须贯穿三条原则：技术分析是**概率工具**而非确定性预测；多数指标存在**滞后性**，信号是统计倾向不是结论；技术面结论须与基本面及其他技能交叉使用，不单独作为买卖依据。

### ① 趋势与结构

- 分析什么：日线与周线的高点 / 低点结构（高点抬高还是降低）、趋势方向（上升 / 下降 / 横盘震荡）、多周期是否一致。
- 怎么判断：道氏思路 —— 高点与低点同步抬高为上升趋势，同步降低为下降趋势，交错为震荡；周线定方向、日线找位置；多周期共振（周线与日线同向）的信号强于单周期。
- 警惕什么：不要用单一根 K 线定义趋势；震荡市里趋势信号频繁失效，须先识别行情性质再套用趋势结论；不同周期结论冲突时如实并列，不强行调和。

### ② 均线系统

- 分析什么：5 / 10 / 20 / 60 / 120 / 250 日均线的方向与排列（多头排列 / 空头排列 / 粘合发散）、股价与各均线的位置关系。
- 怎么判断：短中长期均线依次向上排列为多头排列，反之为空头排列；均线粘合后的发散方向常伴随变盘；股价回踩中长期均线获得支撑 / 跌破失守是强弱分界参考。
- 警惕什么：均线是滞后指标，单看均线会晚于拐点；剧烈波动后均线失真（长期均线被跳空拉平）；不同软件默认参数不同，引用读数时注明参数与来源。

### ③ 动量指标

- 分析什么：MACD（快慢线位置、金叉 / 死叉、背离、零轴上下）、RSI（数值区间、超买超卖、背离）、KDJ（敏感段的交叉）、布林带（带宽、股价相对位置）。
- 怎么判断：指标与价格的背离（价新高而指标不新高）是动量衰减的参考信号；超买超卖在强趋势中会钝化，逆势抄底胜率低；多指标同向印证时信号权重更高。
- 警惕什么：动量指标全部滞后于价格，背离不必然导致反转；指标钝化是趋势市的常态；不同来源的指标读数（RSI 用 14 日还是其他参数）口径不一，引用时注明。

### ④ 量价关系

- 分析什么：放量 / 缩量与涨跌方向的组合、关键位置的量能变化、量价配合度、筹码分布思路（获利盘比例、密集成交区）。
- 怎么判断：放量上涨、缩量回调为健康组合；放量滞涨或放量下跌提示抛压；突破关键阻力位须有量能配合才有效，缩量突破易回补；密集成交区构成支撑 / 阻力的参考。
- 警惕什么：成交量可能受解禁、大宗、指数调仓等非交易意愿因素干扰，异常放量先查原因；筹码指标各家算法差异大，只作定性参考并注明。

### ⑤ 关键价位

- 分析什么：支撑位与阻力位：前高前低、跳空缺口、密集成交区、整数关口、长期均线位置。
- 怎么判断：多个依据重叠的价位（如前高 + 缺口 + 整数关口）权重更高；站稳 / 跌破须以收盘价并配合量能确认，盘中刺破不算有效突破。
- 警惕什么：价位是概率区域不是精确数字，报告一律写「一带 / 附近」；不写死具体点位（用 <价位描述> 占位），避免变成点位预测。

### ⑥ 形态识别

- 分析什么：常见反转形态（头肩顶 / 底、双顶 / 双底）与中继形态（三角形、旗形、箱体）及量度目标思路。
- 怎么判断：形态以突破颈线并量能确认为成立标准，未突破前只是雏形；量度目标只给区间与条件，不给精确目标价。
- 警惕什么：形态识别主观性强，不同分析者画法不同，结论标注「主观判断」；小周期形态噪音大，优先日线级别形态。

### ⑦ 情景推演

- 分析什么：多头情景与空头情景各自的触发条件（什么信号出现则情景成立）。
- 怎么判断：输出条件化的「如果 …… 那么 ……」结构，两个方向都要覆盖；给出各情景下需要跟踪确认的信号（量能、指标、价位）。
- 警惕什么：严禁写成单边预测；情景概率只能定性描述（偏高 / 均衡 / 偏低）并说明依据；禁止给出确定性方向判断（合规红线）。

## 引用与时效

- 每个关键读数（涨跌幅、成交额、指标状态、价位区间）标注来源与数据日期，格式：`来源：东方财富（URL 或页面名，YYYY-MM-DD）`；页面无日期标注时写「日期未标注，未核实」。
- 指标读数与量价数据须有 ≥2 个独立来源交叉验证（东方财富 × 同花顺为常用组合），无法核实的标注「未核实」。
- 行情数据波动快，全文统一用「截至最新可得数据」表述，不写死具体日期、点位与价格；价位一律写「一带 / 附近」。
- 结论与关键判断按三级置信度标注：**确认**（≥2 个独立来源交叉验证一致）、**大概率**（单一可靠来源，或有佐证但未完全交叉验证）、**存疑**（来源单一且可靠性一般，或来源间存在分歧）；形态与情景判断属主观分析，显式标注「判断」。
