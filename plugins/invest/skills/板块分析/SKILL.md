# 板块分析

## 适用场景

当用户就某个板块提出轮动阶段、资金流向、个股梯队、催化剂类问题时触发本技能。
- 中文示例：「半导体板块现在处于什么阶段？」「算力板块主力资金还在流入吗？」
- 英文示例："Where is the semiconductor sector in the rotation cycle?" "Is smart money still flowing into the AI computing sector?"
- 仅涉及个股基本面或大盘宏观、不含板块维度的问题，优先交给对应技能处理。

## 输入确认

- 本技能必须先有明确的板块标的（板块名称，如半导体、算力、创新药、消费电子）。
- 用户未提供任何板块时：不发起联网检索。先输出本技能的使用说明与分析框架概览，列出可分析维度（板块概览、轮动位置、资金流向、个股梯队、估值分位、催化剂、风险），并询问用户要分析哪个板块、重点关注哪些维度。
- 板块口径有歧义时（如「医药」可指创新药、CXO、中药），先与用户确认范围，再开始检索。
- 用户提供标的后，才按「数据检索 → 分析框架 → 输出模板」的顺序执行并输出报告。

## 数据检索

- 检索前先读共享数据源清单：`../../references/data-sources.md`（从本技能文件出发的相对路径），遵守其中的来源优先级与取数规则。
- 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取数据，不依赖本地脚本或付费数据接口。
- 本技能核心来源：
  - 东方财富数据板块（data.eastmoney.com）：板块行情、资金流向（主力净流入）、两融、龙虎榜。
  - 同花顺（10jqka.com.cn）：板块页面、资金流向、技术指标。
  - 财联社（cls.cn）：盘面快讯、盘中异动、题材电报（催化剂与情绪线索）。
- 检索式示例（风格参照 data-sources.md 的检索式模板）：
  - `<板块名> 资金流向 主力净流入`
  - `<板块名> 板块行情 涨幅 排名 东方财富`
  - `<板块名> 涨停 异动 题材 财联社`

## 分析框架

按以下七个维度逐项分析，结论须区分「事实」（有来源）与「分析」（判断 / 推测）。

### ① 板块概览
- 分析什么：板块定义与范围（包含哪些细分方向）、代表指数或成分、近期表现与在全部板块中的排名。
- 怎么判断：用东方财富 / 同花顺板块页确认板块口径、区间涨跌幅与排名，注明口径是行业指数还是概念板块。
- 警惕什么：各平台板块成分不一致，跨平台比较前先统一口径；板块外延模糊时先向用户确认。

### ② 轮动位置
- 分析什么：板块指数日 / 周线趋势、相对大盘强弱（相对收益）、所处轮动阶段（启动 / 发酵 / 高潮 / 退潮）。
- 怎么判断：将板块区间涨跌幅与大盘同期对比，持续跑赢视为相对强势；结合量能、涨停家数、龙头高度判断阶段——低位放量启动、扩散补涨发酵、普涨加速高潮、缩量分化退潮。
- 警惕什么：阶段判断属推测，必须标注置信度；单日强弱不构成趋势结论，不用「见顶」「见底」等确定性表述。

### ③ 资金流向
- 分析什么：板块主力净流入规模及持续性（连续净流入天数）、龙头股的资金承接。
- 怎么判断：以 data.eastmoney.com 资金流页面为主，观察净流入是否连续、大单结构变化；龙头放量承接视为健康，高位放量出逃视为退潮信号。
- 警惕什么：各家「主力 / 大单」统计口径不同，不能跨平台直接比较数字；单日流入不等于趋势。

### ④ 个股梯队
- 分析什么：龙头（人气与涨幅标杆）、中军（大市值核心）、补涨股（低位跟风）三个层次的比较。
- 怎么判断：按市值区间、区间涨幅、逻辑强度（订单 / 业绩 / 题材纯度）分层比较；梯队完整说明板块处于发酵及以上阶段，仅剩龙头独自走强则要警惕。
- 警惕什么：涨幅与市值是事实，逻辑强弱排序属分析推断；无基本面支撑的高位纯题材股风险最大，须明确提示。

### ⑤ 估值分位
- 分析什么：板块整体估值水平（市盈率 / 市净率等）与所处历史分位。
- 怎么判断：检索板块估值与历史分位区间（如低于三成、中位附近、高于九成），注明回溯区间、数据口径与来源。
- 警惕什么：亏损或强周期行业市盈率失真；各平台分位回溯口径差异大，引用时必须注明来源与口径。

### ⑥ 催化剂
- 分析什么：事件日历（政策会议、产业展会、业绩披露窗口）、政策与产业催化（规划文件、订单落地、技术突破）。
- 怎么判断：以官方发布（部委 / 交易所 / 行业协会）与财联社快讯为准，按时间顺序整理成事件表，区分「已落地」与「预期中」。
- 警惕什么：预期落空是常见退潮诱因；自媒体与论坛传闻仅作线索，不得作为催化剂的事实依据。

### ⑦ 风险
- 分析什么：拥挤度（板块成交占全市场比重、换手率、融资买入占比所处水平）、退潮信号（龙头滞涨、补涨股补跌、资金转为净流出）。
- 怎么判断：拥挤度处于历史高位且同时出现高潮阶段特征时，加重风险提示；逐条列出观察到的信号，用框架性表述而非确定性结论。
- 警惕什么：不使用「必跌」「崩盘」等表述；多空两面都要呈现，避免单边叙事。

## 引用与时效

- 每个关键数字（涨跌幅、资金净流入、估值分位、排名）标注来源与日期，格式：`来源：东方财富（URL 或页面名，YYYY-MM-DD）`；页面无日期时写「日期未标注，未核实」。
- 关键数字须 ≥2 个独立来源交叉验证；无法核实的标注「未核实」。
- 行情类数据波动快，统一用「截至最新可得数据」表述，不写死具体日期、价格、点位。
- 结论按三级置信度标注：**确认**（≥2 个独立来源交叉验证一致）、**大概率**（单一可靠来源或有佐证）、**存疑**（来源单一或来源间有分歧）。
- 不同来源数字矛盾时并列列出并说明分歧，不擅自取舍；付费墙来源换用同优先级替代来源，不猜测数据。
