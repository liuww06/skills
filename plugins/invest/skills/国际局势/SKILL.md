## 适用场景

当用户询问国际局势、美国政策或全球宏观事件对 A 股的影响时触发本技能，主题包括关税（tariffs）、制裁（sanctions）、出口管制（export control）、美联储政策（Fed policy）与地缘冲突。
中文提问示例：「美国新一轮关税对 A 股哪些板块有影响？」「实体清单又新增了公司，半导体链怎么看？」
英文提问示例："How will the latest USTR tariffs affect Chinese equities?" "What is the market impact of new BIS export controls?"
泛泛的趋势询问同样适用，如「最近外围环境怎么样，对大盘有什么影响」。
若提问与上述主题无关（如个股财报、纯技术面分析），优先让位给对应专项技能。

## 输入确认

本技能参数可选，无需必填字段。
若用户既未提供事件或主题（如某项关税政策、实体清单调整、地缘冲突、美联储议息），也未表达任何相关意图（例如只是问「这个技能是什么、怎么用」）：输出使用说明与分析框架概览并询问用户想分析的主题，此情形下【不发起联网检索】。
用户一旦给出主题，或明确要求分析（哪怕只是泛泛的『最近怎么样』），即视为输入已确认，直接按本文件框架联网检索并输出完整报告。
报告标题统一为「<事件或主题名称> 对 A 股影响分析（截至最新可得数据）」。

## 数据检索

1. 检索前先读共享数据源清单：`../../references/data-sources.md`（从本技能文件出发的相对路径），遵守其中的来源优先级与取数规则。
2. 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取最新信息，不依赖任何本地脚本或付费接口。
3. 本技能核心来源速查：
   - 美国贸易代表办公室 USTR（ustr.gov）：301 关税、贸易调查与豁免申请
   - 美国商务部 BIS（bis.gov）：出口管制、实体清单（entity list）新增与移除
   - 白宫（whitehouse.gov）：行政命令、总统公告与签署动态
   - 美联储（federalreserve.gov）：FOMC 声明、利率决议、点阵图与主席讲话
   - 中国商务部（mofcom.gov.cn）：反制措施、贸易回应与谈判表态
   - 财新（caixin.com）：政策解读与国内宏观报道
   - 路透中文（cn.reuters.com）：国际政策快讯，用于关键事实交叉验证
4. 检索式示例（风格参照 data-sources.md 的检索式模板，可直接执行）：
   - `USTR 301 关税 中国 最新`
   - `BIS entity list 新增 <行业或公司名>`
   - `FOMC statement 最新` 或 `美联储 议息会议 决议`
5. A 股板块行情与资金验证用东方财富、同花顺等来源；自媒体与论坛讨论仅作线索，不作关键数字引用源。

## 分析框架

### 1. 事件概览与时间线
- 分析什么：发生了什么、涉及哪些主体、当前处于哪个阶段（提议 / 公示 / 听证 / 生效 / 暂停 / 谈判中）。
- 怎么判断：以官方原始文件（USTR 公告、白宫行政命令、BIS 联邦公报、FOMC 声明、中国商务部回应）为准重建时间线，每个节点标注来源。
- 警惕什么：把「媒体披露的意向或草案」当成「已生效政策」；时间线节点缺来源时降级标注「未核实」。

### 2. 政策事实核查
- 分析什么：按政策主体（USTR / 白宫 / BIS / 美联储 / 中国商务部等）逐条核实政策内容、适用范围、豁免条款与生效时间。
- 怎么判断：每条政策单独成行进入核查表格；事实与观点严格分离，事实必须带来源，分析须冠以「判断 / 推测」。
- 警惕什么：标题党转述导致税率或清单范围失真；引用无日期的二手转载；混淆「宣布」与「生效」两个时点。

### 3. 传导路径
- 供应链重构：管制与制裁是否迫使产业链迁移或国产替代提速，跟踪订单、产能与认证进展等信号。
- 成本变化：评估关税的实际承担方与向终端价格的传导弹性，警惕把从价税简单等额计入成本。
- 需求影响：海外需求收缩与「抢出口」效应并存，对照海关进出口与行业量价数据辨别净方向。
- 风险偏好：地缘冲突与政策不确定性对估值与成交情绪的压制，属「判断 / 推测」范畴，须标注置信度。
- 汇率与利率渠道：美元指数、人民币汇率、美债收益率与美联储政策预期如何影响外资流动与成长股估值。

### 4. A 股行业影响矩阵
- 分析什么：把传导路径落到行业层面，区分受益与受损方向，形成矩阵表格。
- 受益方向：进口替代 / 国产化（自主可控）、避险资产、内需对冲链等；受损方向：出口链、外企供应链、高海外收入占比环节等。
- 怎么判断：每个行业给出方向（利好 / 利空 / 中性 / 双向）、一条完整逻辑链与代表板块；涉及收入占比等关键数字须两源验证。
- 警惕什么：只给方向不给逻辑；把短期情绪脉冲当作基本面变化；写死具体点位、价格或股票代码。

### 5. 历史类比
- 分析什么：选取历史上同类事件（此前轮次的关税摩擦、制裁、加息 / 降息周期）当时的市场表现作参照。
- 怎么判断：说明当时的事件强度、政策持续期与市场反应，逐项对比与本轮的异同，不照搬结论。
- 警惕什么：样本量小、宏观背景差异大，类比仅供参照；必须注明样本局限性，不外推精确涨跌幅。

### 6. 后续观察点
- 分析什么：政策时间表（公示期、听证会、投票、生效节点）、谈判与高层互动安排、后续关键数据发布日程。
- 怎么判断：只列可验证的观察项并给出对应官方渠道，方便用户自行跟踪更新。
- 警惕什么：把已排期事件与市场臆测时点混列；无官方时间表的一律标注「时点未官宣，未核实」。

## 引用与时效

- 每个关键数字（税率、清单条目数、利率水平、涨跌幅）标注来源与日期，格式：`来源：<机构或媒体>（URL 或页面名，YYYY-MM-DD）`。
- 关键数字须 2 个独立来源交叉验证；无法核实的标注「未核实」，页面无日期的标注「日期未标注，未核实」。
- 行情与快变量统一用「截至最新可得数据」表述，不写死具体日期、价格与点位。
- 结论与关键判断按三级置信度标注：确认（≥2 个独立来源一致）、大概率（单一可靠来源或有佐证）、存疑（来源单一或来源间有分歧）。
- 不同来源数据矛盾时并列列出并说明分歧，不擅自取舍；区分事实（有来源）与推断，推断处使用「判断 / 推测」字样。
