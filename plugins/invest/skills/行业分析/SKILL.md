## 适用场景

用户提出的问题聚焦在「一个行业整体」而非单只个股或大盘点位时，触发本技能。
典型中文提问：「帮我分析新能源汽车行业的空间和竞争格局」「光伏产业链上中下游怎么拆？」
典型英文提问："Analyze the competitive landscape of the EV industry"、"How is the AI value chain structured?"
涉及行业空间、竞争格局、产业链、景气度、政策影响等维度的中英文提问均适用。
若用户只问单个公司财报、估值或大盘行情，应改用 invest 插件中对应的技能。

## 输入确认

本技能必须先有标的：一个具体的行业名称（如新能源汽车、光伏、人工智能、创新药、存储芯片）。

- 用户未提供任何行业时：**不发起联网检索**。此时输出本技能的使用说明与分析框架概览，
  列出可分析维度（行业空间 / 竞争格局 / 产业链图谱 / 景气度 / 政策环境 / 代表公司），
  并询问用户要分析什么行业、需要快速版还是完整报告；待用户给出标的后再开始检索执行。
- 用户提供标的后：先确认行业口径与边界（如「新能源车整车」还是「锂电全产业链」），
  再按「数据检索 → 分析框架 → 输出模板」的流程执行。
- 行业名称有歧义或范围过大时，先向用户澄清细分赛道，避免检索口径错位。

## 数据检索

1. 检索前先读共享数据源清单：`../../references/data-sources.md`（自本技能文件出发的相对路径），
   按其来源优先级规则选源：法定披露 > 官方机构与主流财经媒体 > 自媒体（仅作线索）。
2. 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取数据，
   不依赖任何本地脚本或付费数据接口。

本技能核心来源：

- 国家统计局（stats.gov.cn）：工业增加值、PMI、价格指数等行业相关宏观与工业数据
- 国家发改委（ndrc.gov.cn）：产业政策、规划文件、投资项目审批
- 行业协会：中汽协（汽车产销）、乘联会（乘用车零售）、中国半导体行业协会等，
  定期发布产销量与价格数据，是行业口径数据的第一优先来源
- 券商行业研报摘要（东方财富 / 同花顺研报频道）：空间测算、份额与产业链拆分线索
- 财新（caixin.com）：产业政策解读与行业深度报道，用于交叉验证

可直接执行的检索式示例（风格参照 data-sources.md 的检索式模板）：

- `<行业名> 市场规模 增速 渗透率 最新`
- `<行业名> 景气度 / 产能 / 库存 / 开工率 最新`
- `site:stats.gov.cn <行业名> <指标名>` / `<行业协会名> <行业名> 产销 最新`

## 分析框架

### ① 行业空间

- 分析什么：市场规模（TAM）与增速、渗透率、需求驱动因素、生命周期阶段（导入 / 成长 / 成熟 / 衰退）。
- 怎么判断：用「量 × 价」拆分规模，区分需求扩张与涨价驱动的增长；低渗透率 + 高增速
  多为成长期，高渗透率 + 增速放缓多为成熟期，结合增速拐点判断阶段切换。
- 警惕什么：不同机构对远期空间的测算假设差异极大，引用时注明测算假设；
  警惕把周期峰值需求当作稳态需求线性外推。

### ② 竞争格局

- 分析什么：市场集中度（CR3 / CR5）、主要玩家及份额、竞争要素（成本 / 技术 / 渠道 / 牌照）、国产替代进程。
- 怎么判断：集中度的变化方向比绝对水平更重要；把份额变化与价格战、技术路线迭代、
  政策洗牌等事件对应起来解释；国产替代看国内厂商份额提升节奏与下游验证进展。
- 警惕什么：销量 / 收入 / 产能三种口径下的份额排名差异大，比较前先统一口径；
  警惕「格局已定」的线性外推，技术路线切换可能重构整个格局。

### ③ 产业链图谱

- 分析什么：上游 / 中游 / 下游环节划分、各环节代表企业与集中度、利润分配与议价权、卡脖子环节。
- 怎么判断：用各环节毛利率 / 净利率分布看利润池位置；议价权看供给集中度、客户切换成本
  与产能松紧；卡脖子环节对照设备、材料、核心零部件的进口依赖与替代进展。
- 警惕什么：环节划分过粗会掩盖真正瓶颈；警惕把阶段性「产能稀缺」误读为永久议价权，
  周期反转后议价权可能迅速转移。

### ④ 景气度跟踪

- 分析什么：价格、库存、开工率 / 产能利用率、订单、产销率等高频指标及近期趋势。
- 怎么判断：价升 + 库存去化 + 开工率高多为景气上行；价跌 + 库存累积多为景气下行；
  指标背离时（如价升库增）用库存周期框架解释，并明示判断的不确定性。
- 警惕什么：单月单指标易误导，必须看连续多期趋势；警惕用低频年度数据冒充高频景气跟踪。

### ⑤ 政策环境

- 分析什么：产业规划（五年规划与专项文件）、补贴与税收、监管与准入、出口管制与贸易政策。
- 怎么判断：区分方向性表述与可执行条款（金额 / 期限 / 覆盖范围）；补贴看退坡节奏与
  常态化机制切换；准入与标准升级看其对中小产能和行业份额的影响；尽量找政策原文。
- 警惕什么：政策预期常被市场提前透支，落地不及预期会造成反向波动；
  警惕把规划目标数值直接当作必然实现的产销量。

### ⑥ 代表公司

- 分析什么：上中下游各环节龙头及其份额、商业模式与核心逻辑（资源 / 技术 / 成本 / 客户绑定）。
- 怎么判断：用「环节格局 + 公司卡位」两步定位——先看所在环节的利润池与议价权，
  再看公司在该环节的份额与竞争壁垒是否可持续。
- 警惕什么：只列名单不给逻辑没有价值；不给个股确定性目标价，不构成个股推荐。

## 引用与时效

1. 每个关键数字（市场规模、份额、集中度、价格、开工率、政策条目）标注来源与数据日期，
   格式：`来源：<站点名>（页面名或 URL，YYYY-MM-DD）`；页面无日期时写「日期未标注」。
2. 关键数字须 2 个独立来源交叉验证；无法核实的一律标注「未核实」，不得当作事实使用。
3. 报告统一使用「截至最新可得数据」表述，不写死具体日期、价格、点位。
4. 结论与关键判断按三级置信度标注：**确认**（≥2 个独立来源交叉验证一致）、
   **大概率**（单一可靠来源或有佐证但未完全交叉验证）、**存疑**（来源单一且可靠性一般，或来源间有分歧）。
5. 不同来源数字矛盾时并列列出并说明分歧来源，不擅自取舍。
6. 区分「事实」（有来源）与「分析」（模型推断），推断处使用「判断 / 推测」字样。
