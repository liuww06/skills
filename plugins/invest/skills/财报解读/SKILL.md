## 适用场景

用户希望解读某家公司的定期报告（季报 / 半年报 / 年报）、业绩预告 / 业绩快报，或增减持、回购、重组并购、分红送转、担保质押等各类公告时，触发本技能。

- 中文示例：「<公司名> 最新一季财报业绩成色如何」「<公司名> 的增持公告和年报商誉怎么看」
- 英文示例："Summarize the latest quarterly earnings of <公司名>"、"What does the share buyback announcement of <公司名> imply?"

纯宏观、行业景气、技术面行情类提问不属于本技能范围，应转由对应技能处理。

## 输入确认

1. 本技能必须先有标的：公司名称或股票代码，可附报告期间（如 <年度>Q<季度>、<年度>年报、<年度>业绩预告）；未注明期间则默认解读最新一期报告。
2. 若用户未提供任何标的：
   - 不发起联网检索；
   - 输出本技能使用说明与分析框架概览（即下文「分析框架」六大维度的一页式摘要）；
   - 列出可分析维度：业绩概览、收入利润拆解、现金流与资产质量、口径差异核对、公告要点解读、雷区信号；
   - 询问用户要分析哪家公司、关注哪个报告期间或哪类公告。
3. 用户提供标的并确认期间后，才按「数据检索 → 分析框架 → 输出模板」执行。
4. 标的存在歧义（同名公司、A/H 或多地上市）时，先向用户确认再检索。

## 数据检索

1. 检索前先读 `../../references/data-sources.md`（自本技能文件出发的相对路径），遵循其来源优先级与取数规则。
2. 使用可用的联网搜索 / 网页读取工具（如 WebSearch / WebFetch）获取公告原文与财报数据，不依赖本地脚本或付费接口。
3. 本技能核心来源：
   - 巨潮资讯网（cninfo.com.cn）：法定披露平台，年报 / 季报 / 业绩预告 / 各类公告原文，数字以此为准；
   - 东方财富公告与财报页（eastmoney.com）：公告聚合与 F10 财务摘要，用于快速定位与交叉验证；
   - 上交所官网（sse.com.cn）/ 深交所官网（szse.cn）：沪市 / 深市公司公告、监管函件与问询回复。
4. 检索式示例（风格参照 data-sources.md 模板，可直接执行）：
   - `site:cninfo.com.cn <公司名> <年度> 年度报告`
   - `<公司名或代码> 业绩预告 <年度或季度>`
   - `<公司名> 东方财富 F10 财务分析 主营构成`
5. 遇付费墙或无法访问时换用同优先级替代来源，不猜测数据；检索结果矛盾时并列列出并说明分歧，不擅自取舍。

## 分析框架

### ① 业绩概览
- 分析什么：营业收入、归母净利润、扣非归母净利润的同比与环比，单季与累计口径分列。
- 怎么判断：先看增速方向与量级，再看营收与利润增速是否匹配；对照业绩预告区间看兑现度；增速异常先查上年基数。
- 警惕什么：用累计数掩盖最新单季恶化，或用单季亮点掩盖累计下滑；上年同期一次性损益造成的基数失真。

### ② 收入利润拆解
- 分析什么：分产品 / 分地区收入结构与各自增速；毛利率与净利率变化；销售 / 管理 / 研发 / 财务四项费用率；非经常性损益识别——政府补助、公允价值变动、资产处置收益、投资收益等一次性项目的金额与占利润总额比重。
- 怎么判断：定位拉动或拖累业绩的核心业务；毛利率变化归因于售价、成本、产品结构还是会计政策；费用率与营收增速对比看投入效率；对比扣非归母净利润与归母净利润的差异及非经常性损益占比，占比持续偏高时下调利润成色与可持续性评价。
- 警惕什么：毛利率显著高于同行且无可信解释；研发投入资本化比例突增；靠压缩研发或销售费用短期撑利润。

### ③ 现金流与资产质量
- 分析什么：经营现金流净额与净利润的匹配（净现比）；应收账款与存货的同比及周转变化；商誉规模与减值测试；有息负债规模与结构。
- 怎么判断：净现比长期显著低于 1 需追问利润含金量；应收 / 存货增速持续快于营收提示回款与压货风险；商誉占净资产比例高时核对被收购方业绩承诺完成度。
- 警惕什么：大存大贷（货币资金充裕却高息举债）；应收激增叠加客户集中度上升；存货跌价与商誉减值计提明显不足。

### ④ 口径差异
- 分析什么：业绩预告（区间预估）、业绩快报（初步核算）、正式报告（年报经审计、季报未经审计）三者的口径差异与核对方法。
- 怎么判断：数字以正式报告为准；预告 / 快报与正式值差异大时，核查公司是否发布修正公告及原因；区分预增 / 预减 / 扭亏 / 续亏类型与同比口径。
- 警惕什么：预告与快报之间「变脸」；快报与审计后年报差异超出合理范围；忽略「季报未经审计」提示就下重结论。

### ⑤ 公告要点解读
- 分析什么：增减持（主体身份、数量占比、窗口期合规）；回购（注销或激励目的、金额上下限、进展）；重组并购（交易结构、业绩承诺、商誉影响）；分红送转（分红率、股息率、送转比例）；担保质押（担保对象与总额占比、质押比例）。
- 怎么判断：区分信号强度——大股东真金白银增持、回购并注销偏正面；密集减持、高比例质押偏负面；重组看支付对价方式与承诺业绩的可实现性。
- 警惕什么：金额下限极低的「象征式」回购或增持；对外担保总额占净资产比例过高；质押比例逼近警戒线带来的平仓连锁风险。

### ⑥ 雷区信号
- 分析什么：业绩变脸（预告修正方向反转）、大存大贷、应收激增、存货异常、关联交易占比与定价、审计意见类型。
- 怎么判断：多信号叠加时整体风险等级上调，单一信号仅作提示不单独定论；关联交易看占比趋势与定价公允性；非标审计意见（保留意见、无法表示意见、带强调事项段）是强警示。
- 警惕什么：临近披露期更换会计师事务所或年报难产；靠其他收益与营业外收入撑利润；存货与应收同增且经营现金流同步恶化。

## 引用与时效

1. 每个关键数字（营收、利润、现金流、增减持比例、质押比例等）标注来源与数据日期，格式：`来源：巨潮资讯网（公告标题或 URL，YYYY-MM-DD）`；页面无日期时写「日期未标注，未核实」。
2. 关键数字须 ≥2 个独立来源交叉验证（如巨潮公告原文 + 东方财富财报页），验证一致方可作为结论依据。
3. 无法核实或仅有单一来源的数字，标注「未核实」，不得冒充已验证。
4. 报告统一以「截至最新可得数据」表述，不写死具体日期、价格、点位。
5. 结论与关键判断按三级置信度标注：确认（≥2 个独立来源一致）、大概率（单一可靠来源或有佐证未完全交叉验证）、存疑（来源单一或来源间有分歧）。
6. 区分「事实」（有来源）与「分析」（推断），推断处使用「判断 / 推测」字样。
