name: greeting
description: Use when the user asks to be greeted, says hello, or wants a friendly demo of how plugin skills work. Greets the user warmly and offers help.
---

Greet the user warmly and briefly.

1. Address the user by name if known, otherwise use a friendly generic greeting.
2. Keep it to one or two sentences — no long preamble.
3. Close by offering help, e.g. ask what they would like to work on today.

This skill is a minimal example shipped with the `hello-world` plugin. When writing
your own skills, model them on this file: a directory under `skills/` containing a
`SKILL.md` with a `name` and a `description` that clearly states when the skill
should trigger.
